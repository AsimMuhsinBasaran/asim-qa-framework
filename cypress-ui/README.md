# Cypress UI Workspace

This workspace is the Cypress + TypeScript UI layer of the unified QA ecosystem.

## What it is for

- browser-level smoke and flow validation
- UI assertions and screenshots
- future API-to-UI cross checks using runtime bridge files

## What it is not for

- backend request orchestration
- shared Java test logic
- direct coupling to the Java runtime classes

## Install

From the workspace root:

```bash
cd cypress-ui
npm install
```

## Run

```bash
npm test
npm run test:open
npm run test:headed
```

## Runtime Context Bridge

The Cypress workspace can read a runtime context JSON artifact generated by the Java framework.

Default path:

```text
../test-data/runtime/context.json
```

You can override it with:

```bash
RUNTIME_CONTEXT_FILE=/path/to/context.json npm test
```

If the file does not exist, the reader returns an empty context and a controlled warning instead of failing the spec.

## Current status

There are no real application UI flows here yet.
The initial smoke spec only verifies that Cypress starts and that the runtime context reader behaves safely when the file is missing.
